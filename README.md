# DAM-Estudio

Repositorio dedicado a mis proyectos, ejercicios y prácticas realizados durante el Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

Documentar mi aprendizaje, desarrollar mis habilidades de programación y mostrar mi evolución mediante proyectos prácticos.

## Tecnologías

- **C# y .NET:** programación orientada a objetos y aplicaciones.
- **Python:** fundamentos de programación.
- **Java:** desarrollo de aplicaciones.
- **SQL:** bases de datos relacionales.
- **HTML y CSS:** desarrollo y estructura de interfaces web.

## Proyectos

### Simulador de IVA y préstamos — C#

Aplicación de consola desarrollada en C# que incluye cálculos de IVA y un simulador de préstamos con amortización de capital constante.

El simulador calcula intereses sobre el saldo pendiente, cuotas mensuales y el importe total a devolver.

**Estado:** Finalizado.
